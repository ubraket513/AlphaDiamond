# AlphaDiamond training control
Local training/evaluation tool for one operator. Current native stage, iteration and cumulative steps lead the page, followed by losses and throughput.

Light mode only, drawing the shell from the local PhX-UI reference. White workspace #ffffff, text #1a1b1f, secondary text #64666f, rules #e1e2e6, accent #005dbe. Existing blue, amber and lilac chart series. Locally served Pretendard 400/500/600/700 for body, key numbers and charts; monospace for console and technical identifiers. 15px base, 24px page heading. No top title bar. Sticky 240px gray job rail with a home icon/link at the top fading from #e8edf2 to #f7f7f7, main padding 30px 40px. New-training action at rail bottom. White content sections divided by thin rules, no chart cards or shadows. Plots 320px high, 360px on wide desktops. Existing text-only AlphaDiamond brand; no image assets. Preserve native Svelte implementation, no React or PhX runtime dependency.

Korean interface with native identifiers preserved. Chart.js line plots with hover values and clickable legends. GPU memory uses adaptive SI units (B, KB, MB, GB, TB) on ticks and tooltips. Mouse-wheel zoom over either plot selects the same training-step interval on both charts around the cursor, without a reset button or separate slider. Full range follows new data; a selected end remains fixed. Native progress.json supplies live stage counts and latest metrics. Chart history updates at stage completion. Visible charts average 150 step intervals, with subtle fading area fills. Key numbers roll and briefly flash green or red on changes. Details/summary for path, TF32 requests and command. Empty console is a brief line. On mobile, jobs form a horizontal list and plots stack without horizontal overflow.

Remove secondary instructional copy, chart counts, footer and local connection status. Use labeled/tooltipped icon actions for copy, stop, close and external console. Native trainer stderr emits stage and progress logs; stdout remains final JSON.

Resources: Linux Resources-inspired Processor (blue), Memory/Swap (pink), GPU usage/VRAM (red). Sidebar sparklines select a centered hardware heading and rounded, lightly tinted detail graphs. Real system-wide samples every second; 120-point client history begins at a zero baseline and updates without replaying chart animations. Current numeric values are actual observations.

Controls follow PhX/Astryx: shared Svelte selects use the native Popover API for an opaque white menu with a fine border, soft shadow, blue selection and checkmark. Opening and closing use PhX's 160ms cubic-bezier(.24,1,.4,1), 8px movement and .95 scale; reduced motion disables transitions. Arrow/Home/End selection, Enter/Space, Escape, Tab and outside dismissal are supported. No React or UI library dependency. Progress uses an 8px neutral track, fully rounded solid accent fill and a 200ms ease-out width transition; reduced motion disables it. Throughput defaults to samples/min; clicking the unit cycles seconds/minutes/hours and converts the value, badge and chart immediately without changing the 10s sample cadence. Recent loss holds the arithmetic mean of the latest complete global 1,000-step block, with the actual range available on hover; live updates require the new native trainer process.

The training launcher is a separate settings page with basic, learning, self-play, limits and runtime groups. PhX settings fields have muted fills, 12px corners, 2px blue focus rings and persistent red invalid borders; JSON errors describe their editor. Buttons use PhX's 2px focus outline with a 3px offset. Icon tooltips are opaque white and match the 12px/20px type, 8px corners and 6px 10px padding, appear on hover/focus and dismiss with Escape. Selected tabs are semibold with a blue underline. NVIDIA-style badges show the loss change from the preceding complete 1,000-step block and throughput change from the preceding 10s display, with arrows and pale green/red backgrounds. Throughput digits update every 10s; cumulative steps have no rolling or color animation. Other reels decelerate using cubic-bezier(.16,.55,.2,1), with digit durations of 1800ms plus 160ms per character position. Color holds through the complete roll and fades to black over 300ms.
