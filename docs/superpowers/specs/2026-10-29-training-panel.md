# Training control panel

The user authorizes autonomous implementation and Min training until 2026-10-29 16:20:02 KST. Development happens on local branches in `/home/dohyoung-ko/AlphaDiamond`, with Desktop independently in `/home/dohyoung-ko/AlphaDiamondDesktop`. Existing changes and training artifacts must remain recoverable.

Build a small local Svelte panel for the person running training. It must list active native CLI training processes, including Agent-launched ones; show their settings, native state, console output and all available stage metadata; chart total/policy/value loss and throughput; and let the person edit a configuration and launch training. Stop terminates the selected training immediately. There is no failed-job history, termination-reason display, agent notification, database, persistent job registry, retry or fallback framework.

Use Svelte 5 and Vite, with a thin Node built-in HTTP bridge bound to loopback. Use native SVG for charts, system fonts, and no additional UI/server/chart frameworks. A compact dark workspace has an active-run list, selected-run overview/charts/logs, and a configuration/start area. Provide labelled controls and a usable narrow layout. New training settings start from the existing JSON presets, with convenient fields for common values and a complete JSON editor so every native setting remains available.

Discover active `alphadiamond-train train/resume` processes from Linux `/proc`, resolving `--run-dir` against process cwd. Read their native files; no registration step is required. Run state is `state.json`; effective settings are `active-config.json` when an accepted resume transition has created it, otherwise `resolved-config.json`. Live output is `console.log`, per-iteration training metrics are `iterations/N/train.json`, and self-play metadata is `iterations/N/selfplay.metrics.json`. Read stages at durable boundaries without representing missing stage output as a failure. Native metrics are emitted per training step after a train stage. The UI must accurately describe this cadence. A raw metadata view preserves access to fields not given a dedicated chart.

Bridge API: `GET /api/status` returns `{jobs:[{pid,runDir,command,startedAt,state,config,metrics,iterations,log}]}`. `metrics` is an ordered flat array of native training metrics with `iteration`; `iterations` contains per-iteration stage/self-play metadata. `GET /api/configs` returns `{configs:[{name,path,config}]}` from `configs/alphazero/*.json`. `POST /api/runs` accepts `{runDir,config,warmStart?}`, writes a config inside the new run directory and launches the configured native binary detached with output at `console.log`, returning `{pid,runDir}`. `POST /api/runs/:pid/stop` immediately sends SIGKILL to the discovered training process; kill its process group only when it is its own group leader. Return `{stopped:true}`. Use actual native validation where available; do not duplicate the C++ config schema. API errors carry `{error:string}` and appropriate status. `ALPHADIAMOND_TRAIN_BIN` selects the binary; default `build/native-training-release/native/alphadiamond-train` in the repository. Default panel port 5178, development Vite port 5173 proxies `/api`.

Keep tests focused on the actual contract: discovering independently launched jobs, native settings/metadata/loss extraction, creating the actual CLI command, and immediate termination. Frontend build and browser verification cover selecting active runs, configuration/start, charts, logs and stop. Never stop the real Min experiment during UI tests.

Use Serena and Graphify for relevant source relationships, Context7 for library APIs, and update the graph after supported code changes. C++ development remains GCC+mold+sccache+Ninja with `-O0 -g1 -pipe`, no LTO, parallel compilation and tests. Production Min training uses a separate optimized Release build. Training runs and evaluations use dedicated ignored artifact directories and never overwrite shipped models. Strength is established by fixed before/after arenas against the exact shipped-model migrated baseline, with uncertainty and aborts reported; loss alone does not establish strength.
